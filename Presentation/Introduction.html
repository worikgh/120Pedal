Uses * LV2 simulators * Jack Audio pipes * Some other stuff I care not about

Problems

I want to use this live

I want to keep using it live and I want to make my own pedals

  • Only uses LV2. Jack can carry any audio
  • Switching time of hundreds of milliseconds
    • Python all the way up and all the way down
  • Not very portable
    • Python 3.10 is not compatible with Python 3.11
    • Can work around but a very loud warning that this will not keep working with updated OS

(Activate on release - Aghhh….)

Solution

  • Set up all the simulators in memory
  • Connect the “pedalboards” with the Jack audio pipes between them
    • Do not set them up with I/O to the hardware devices
  • Write a MIDI controller to change Jack audio pipes to enable I/O

More Problems

  • Pisound hardware feels delicate

    • The case is inadequate
      • Power supply will not connect if front plate attached
    • Without front plate female jacks for audio I/O are vulnerable to metal fatigue of solder joints

    Not confidence inspiring nor attractive

    Solution: Mark II

    • Stay with Raspberry Pi 5
    • Use a different case
      • Regrets: Should have used official 7” screen 3.5” too small

  • Use a USB “sound card”

    • Cheap and cheerful (irritating I/O female sockets - 3mm plugs are not serious…)
    • Lowest rated latency (not cheap at all ~$300)

There are many choices….

Not Finished Yet

  • Adjusting settings interrupts creative process
  • Most important setting is volume
    • Difficult to estimate subjective and relative volume of electric guitar on its own - as opposed to “full noise”
  • Use pd (Pure Data) to make simple mixer to control volume

(This mixer only ever has input on one channel. It does not correctly mix audio data for more than one channel)

Complications

  • Out of order: Mixer => Touch screen - for control
  • Use OSC to control mixer
    • A simple protocol
    • Supported by pd
  • Power Supply: 5v, 5A => 25W
    • Too much for some solutions :-(
  • Reboots if power cycles - power surprisingly reliable on stage, but not at sound check
    • 90 seconds for reboot is an eternity if waiting for it to get sound check
    • Soundees… Unreliable drunks, except for rare and valuable exceptions.
    • Offer love, drugs, sex, money… In my experience nothing helps
